# Sabrland
Minimalist Saber-style customization for Hyprland

# dependencies:
 - sddm
 - qt5-multimedia
 - brightnessctl
 - gst-plugins-good
 - gst-libav
 - qt5-x11extras
 - gst-plugins-bad
 - gst-plugins-ugly
 - fastfetch
 - zsh
 - kitty
 - rofi
 - waybar
 - hyprpaper
 - nerd-fonts
 - grim
 - slurp
 - wl-clipboard
 - papirus-icon-theme
 - dolphin (optional: You can use your own file manager)
 - dunst
 - polkit-kde-agent
 - xdg-desktop-portal-hyprland
 - mesa vulkan-radeon linux-firmware libva-mesa-driver (For AMD GPU ONLY)
 - Arch Linux (optional: I recommend using Arch linux but if you want, you can use any distro you like. Just keep in mind that it may not work properly)
